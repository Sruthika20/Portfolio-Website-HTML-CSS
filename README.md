# Portfolio Website (HTML & CSS)

## 📌 Project Overview
This is a multi-page portfolio website built using HTML and CSS.  
It demonstrates structured webpage design, navigation between pages, and external styling using CSS.

## 🛠️ Technologies Used
- HTML5
- CSS3

## 📂 Project Structure
- index.html – Home page
- contact.html – Contact page
- hobbies.html – Hobbies page
- style.css – Styling for all pages

## ✨ Features
- Clean multi-page layout
- External CSS styling
- Organized file structure
- Basic navigation between pages

## 🎯 Learning Objectives
This project was developed as part of a Full Stack Web Development course to:
- Understand HTML page structure
- Link multiple web pages
- Apply CSS styling
- Build a structured portfolio layout

- Make the website responsive

- Improve UI design
